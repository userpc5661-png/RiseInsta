# RiseInsta

تويك إنستغرام مفتوح المصدر. المميزات الحالية:

- **الوضع الشبح**: إخفاء المشاهدة في الرسائل، منع علم الكتابة، عدم تسجيل مشاهدة الستوري
- **إزالة الإعلانات**: حذف المنشورات الممولة من الفيد
- **التحميل**: زر تحميل على الصور والفيديو (حفظ في الصور أو مشاركة)
- **منيو إعدادات** داخل التطبيق، كل سويتش يتحكم في ميزته مباشرة

## البناء

يتبنى تلقائيًا بـ GitHub Actions مع كل push.
**Actions** ← آخر تشغيل ← **Artifacts** ← `RiseInsta` (فيه `RiseInsta.dylib` و `.deb`).

## الحقن

```bash
cyan -i Instagram.ipa -o RiseInsta.ipa -f RiseInsta.dylib
```
أو Sideloadly (Inject dylibs) / eSign.

## ملاحظة

أسماء كلاسات إنستغرام تتغير مع التحديثات؛ لو توقّفت ميزة بعد تحديث، تُحدّث أسماء الـ hooks.
